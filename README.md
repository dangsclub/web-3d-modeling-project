# 🎨 3D 모델링 검색 및 정밀 코칭 프로젝트 (Web 3D Search & Sculpt Coach)

> 사용자가 원하는 모델을 검색하면, 시스템이 해당 레퍼런스를 제시하고 와콤 펜의 필압과 정밀 수치 조작을 단계별로 코칭해 주는 3D 스컬프팅 웹 플랫폼입니다.

---

## 🚀 주요 기능
- **검색 시스템 (Search Engine):** "활 쏘는 장군", "전사", "로봇" 등 키워드 검색 시 맞춤형 목표 3D 모델과 튜토리얼 자동 생성
- **정밀 코칭 가이드 (Precision Coaching):** "필압 0.4 수준으로 0.5cm 밀어내기" 등 구체적인 펜 조작 수치 및 지시사항 제공
- **와콤 펜 필압 연동 (PointerEvent):** 펜의 압력 감지에 따른 실시간 3D 정점(Vertex) 변형 및 필압 게이지 시각화
- **2열 분할 워크스페이스:** 왼쪽 목표 모델 뷰어와 오른쪽 실습 캔버스의 완벽한 동기화
