# 🎨 3D 모델링 따라 그리기 웹 프로젝트 (Web 3D Modeling Tutorial)

> 와콤 패드와 펜을 활용해 웹 브라우저 화면을 보며 3D 모델링의 기초 과정을 단계별로 학습하고 따라 해볼 수 있는 인터랙티브 웹 프로젝트입니다.

---

## 🚀 프로젝트 소개
이 프로젝트는 복잡한 설치 프로그램 없이 웹 브라우저 상에서 Three.js를 활용해 3D 도형과 모델의 변형 과정을 직관적으로 익힐 수 있도록 제작되었습니다. 
와콤 펜의 정밀한 조작 감각을 살려, 튜토리얼 단계를 넘겨가며 3D 구조가 변화하는 과정을 학습합니다.

---

## ✨ 주요 기능
- **인터랙티브 3D 뷰어:** Three.js 및 OrbitControls를 활용한 360도 회전, 확대/축소 기능 제공
- **단계별 따라하기 (Step-by-Step):** 버튼 조작에 따라 기본 큐브에서 기둥, 구형 모델로 형태가 변화하는 가이드 튜토리얼
- **와콤 펜 최적화:** 펜 드래그 및 정밀 조작에 최적화된 웹 UI 환경
- **SEO 및 수익화 준비:** 구글 애드센스 및 검색엔진 최적화(SEO) 메타 태그 기본 탑재

---

## 🛠️ 기술 스택 (Tech Stack)
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **3D Graphics:** Three.js (r128)
- **Deployment:** Vercel / Netlify / GitHub Pages
