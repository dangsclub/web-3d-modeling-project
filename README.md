# 🎨 3D 모델링 이미지 검색 및 정밀 가이드 코칭 프로젝트

> 원하는 모델을 검색하여 이미지 팝업에서 레퍼런스를 선택하고, 전체 제작 공정 스텝과 시연 가이드를 보며 와콤 펜으로 정밀하게 따라 그리는 3D 실습 플랫폼입니다.

---

## 🚀 주요 기능
- **이미지 검색 및 선택 팝업:** 검색어 입력 후 버튼을 누르면 레퍼런스 이미지 카드 목록 팝업창이 뜨며, 선택 시 좌측 뷰어에 즉시 반영
- **전체 스텝 나열 및 네비게이션:** 최종 완성 단계까지의 모든 공정 스텝이 하단에 pill 형태로 나열되어 자유롭게 이동 가능
- **시연 가이드 영역:** 펜으로 어떻게 스컬프팅해야 하는지 보여주는 시연 가이드 패널 장착
- **와콤 펜 필압 연동 스컬프팅:** 펜의 누르는 압력에 따른 실시간 3D 정점 변형 및 필압 바 시각화
